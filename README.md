# حكاية ولَوِّن | النسخة الاحترافية 1.1

واجهة عربية متجاوبة لإعداد كتب الأطفال، تثبيت أوصاف الشخصيات، إنشاء مخطط صفحات قابل للتحرير، تجهيز وصف فني لكل صفحة، وحفظ المشروع محلياً وتصديره بصيغ JSON وTXT.

## التشغيل
1. تثبيت Node.js.
2. داخل مجلد المشروع: `npm install`
3. تشغيل التطوير: `npm run dev`
4. بناء نسخة النشر: `npm run build`

## النشر على Cloudflare Pages
ارفع الملفات إلى GitHub ثم اربط المستودع بـ Cloudflare Pages:
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`

## حدود النسخة الحالية
زر «توليد مخطط الكتاب» يعمل وينشئ الصفحات وعناوينها ومشاهدها داخل التطبيق. هذا ليس توليد صور فعلياً بالذكاء الاصطناعي. توليد الصور يتطلب مزوّد صور ومفتاح API محفوظاً في الخادم، وليس في ملفات الواجهة. تصدير PDF/PNG النهائي يحتاج مرحلة إخراج إضافية بعد ربط الصور.
